# Memory Match App

A memory matching game developed using Flutter and Dart.

## Project Description

This project is a memory matching game. The player needs to find all matching animal card pairs. The game contains 20 cards, including 10 different animal pairs.

When the player taps a card, the card flips and shows an animal image. If two selected cards match, they remain open with a green check mark. If they do not match, they flip back automatically after a short delay.

## Main Features

- Flutter/Dart implementation
- 20 cards with 10 matching animal pairs
- Animal image assets
- Random card order
- Move counter
- Restart button
- Matching logic
- Green check mark for matched cards
- Congratulations dialog after completing the game
- Responsive design for Chrome web and Android emulator

1. Open the project in Android Studio.
2. Run `flutter pub get`.
3. Select Chrome web or Android Emulator.
4. Click the Run button.
